# SyncPet

好きなキャラクターと暮らす、ブラウザ内保存のAI育成ゲーム。キャラクターの設定・画像・背景を変更できます。

- [Web版を開く](https://syncpet.8bitcanvas.com/)
- [配布版をダウンロード](https://github.com/8bitcanvascode/SyncPet/releases/latest)
- [ゲーム説明書](https://syncpet.8bitcanvas.com/manual.html)

## Windowsで起動する

1. Python 3をインストールします。
2. Releaseの「Assets」から **SyncPet-local.zip** をダウンロードし、すべて展開します。GitHubが自動生成する「Source code」は配布版ではありません。
3. **SyncPetを起動.cmd** をダブルクリックします。
4. 終了するときは、起動時に開いたターミナルで **Ctrl+C** を押します。

スマートフォンではWeb版を利用してください。AIとの会話には、ご自身のGeminiまたはOpenAIのAPIキーとインターネット接続が必要です。API利用料金は各サービスの契約に従います。

## データとAPIキー

育成データは利用中のブラウザに保存されます。ブラウザ間・端末間では自動同期しません。設定からCSVでバックアップできます。画像は別に保存してください。Web版とローカル版のデータも別々です。

APIキーは初期設定では保存しません。希望する場合は、パスフレーズで暗号化して端末内に保存できます。キーはAIサービスに直接送信され、運営サーバーには送信しません。ただし、配信ページや端末が改ざんされた場合などの漏洩を完全には防げません。利用は自己責任となり、運営者は漏洩による損害の責任を負えません。漏洩が疑われるときは、発行元ですぐキーを無効化してください。削除方法はゲーム説明書に記載しています。

このプログラムはChatGPTのCodexを使用して作成しています。
